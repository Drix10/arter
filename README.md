# Arter: Free HTML Portfolio and Blog Website Template

**Arter** is a free, multi-page **portfolio and blog website template** built with HTML, CSS and JavaScript. Use it to showcase your work, write posts and take messages from visitors.

## Pages

| File | Page |
|---|---|
| `home.html` | Portfolio home |
| `history.html` | Timeline / experience |
| `blog-2-col.html`, `blog-3-col.html` | Blog grids |
| `blog-post.html` | Single post |
| `contact.html` + `mail.php` | Contact form |

## Use it

```bash
git clone https://github.com/Drix10/arter.git
cd arter
# open home.html in your browser, then edit the text and images in img/
```

Free to use for personal and commercial portfolios.
